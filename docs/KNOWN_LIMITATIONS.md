# Limitaciones conocidas

- Los modelos y servicios API comerciales pueden cambiar después del periodo experimental.
- Los valores predeterminados de endpoints diferentes no tienen por qué ser equivalentes.
- Los documentos EBAU proceden de organismos terceros y requieren revisión individual de sus condiciones de reutilización antes de un depósito público.
- El inventario contiene columnas para URL y fecha de acceso que deben completarse cuando se identifique de forma fiable el portal institucional de cada PDF.
- La reproducción exacta se garantiza para las etapas deterministas de análisis a partir de los registros preservados, no para nuevas inferencias probabilísticas.
