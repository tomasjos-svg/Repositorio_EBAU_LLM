# Diccionario general de datos

- **Problema**: unidad experimental correspondiente a un ejercicio EBAU.
- **Condición experimental**: combinación de modelo, API y configuración de inferencia.
- **Réplica**: ejecución repetida de un mismo problema bajo una condición.
- **Respuesta generada**: solución producida por el modelo.
- **Evaluación automática**: puntuaciones y clasificación emitidas por el LLM juez.
- **Score**: valoración global.
- **Completeness**: grado de resolución de todos los apartados.
- **Symbolic correctness**: corrección de operaciones y manipulación simbólica.
- **Pedagogical quality**: claridad y utilidad pedagógica.
- **Faithfulness**: fidelidad al enunciado.
- **Subpart accuracy**: precisión por apartados.
- **Error técnico**: registro de una incidencia de ejecución, conservado para trazabilidad.

Los nombres exactos de campos se preservan en los JSON y en los scripts del pipeline.
