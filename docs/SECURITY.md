# Seguridad y credenciales

El repositorio no debe contener claves API. Se ha realizado una búsqueda automática de patrones de claves y se han sustituido las coincidencias detectadas. Aun así, antes de publicar conviene repetir una revisión con una herramienta de detección de secretos. Toda clave que haya aparecido previamente en una copia compartida debe revocarse.
