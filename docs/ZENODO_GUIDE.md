# Publicación en Zenodo

1. Crear un nuevo depósito.
2. Subir el ZIP completo o, si Zenodo exige fraccionamiento, todos los volúmenes indicados en el archivo de partes.
3. Título: usar el título del repositorio o el del artículo.
4. Tipo de recurso: Dataset o Software; si se desea máxima claridad, pueden hacerse dos depósitos vinculados, pero este paquete está preparado como depósito combinado.
5. Licencia del registro: CC BY 4.0 para los contenidos originales. En la descripción debe indicarse que el código usa MIT y que los documentos EBAU de terceros quedan excluidos de la licencia del depósito.
6. Reservar el DOI antes de publicar si se necesita incluirlo en el manuscrito. Zenodo permite obtener el DOI reservado.
7. Publicar el depósito.
8. Añadir el DOI y la URL resultantes a `CITATION.cff` y `README.md` en una versión 1.0.1 o posterior.

Un **marcador de DOI o URL** era simplemente texto provisional como `TO_BE_COMPLETED`. En esta versión no se ha inventado ningún identificador: se explica dónde añadirlo cuando Zenodo lo asigne.
