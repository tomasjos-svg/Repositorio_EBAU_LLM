Solucion oficial

Ejercicio 2) Calcula el siguiente límite:

\[ \lim_{x\to +\infty}\left(\frac{x^2+x+1}{x^2+3x+1}\right)^{x^2\ln 2} \]

Solución oficial:

\[ \lim_{x\to+\infty}\left(\frac{x^2+x+1}{x^2+3x+1}\right)^{x^2\ln2} = e^{\lim_{x\to+\infty} x^2\ln2\cdot \ln\left(\frac{x^2+x+1}{x^2+3x+1}\right)} \]

\[ = e^{\ln2\cdot \lim_{x\to+\infty} x^2 \ln\left(1+\frac{-2x}{x^2+3x+1}\right)} \]

Se obtiene una indeterminación de tipo número \(e\). Aplicando el procedimiento indicado en la solución:

\[ \lim_{x\to+\infty} x^2\ln\left(1-\frac{2x}{x^2+3x+1}\right) \]

\[ = \lim_{x\to+\infty} \frac{\ln\left(1-\frac{2x}{x^2+3x+1}\right)}{1/x^2} \]

Aplicando L’Hôpital:

\[ = \lim_{x\to+\infty} \frac{\frac{-2(x^2+3x+1)+2x(2x+3)}{(x^2+3x+1)^2}}{-2/x^3} \]

Finalmente, el límite del exponente es:

\[ \ln 2 \cdot (-2) \]

Por tanto:

\[ \lim_{x\to+\infty}\left(\frac{x^2+x+1}{x^2+3x+1}\right)^{x^2\ln2} = e^{-2\ln2} = \frac{1}{4} \]

Respuesta A

Para resolver el ejercicio 2 del documento, debemos calcular el límite propuesto:

\[ \lim_{x\to +\infty}\left(\frac{(x+1)^2}{x^2+3x+1}\right)^{\ln x}. \]

Paso 1: Simplificación de la Función Base

Primero simplificamos la expresión dentro del paréntesis:

\[ \frac{(x+1)^2}{x^2+3x+1} = \frac{x^2 + 2x + 1}{x^2 + 3x + 1}. \]

Para \(x \to +\infty\), podemos ignorar los términos de menor grado en el numerador y el denominador:

\[ \frac{x^2 + 2x + 1}{x^2 + 3x + 1} \approx \frac{x^2}{x^2} = 1. \]

Por lo tanto, a medida que \(x \to +\infty\), la expresión tiende a 1. Sin embargo, para ser más precisos en nuestra aproximación, consideramos los términos lineales y separamos \(x^2\) tanto en el numerador como en el denominador:

\[ \frac{(x+1)^2}{x^2+3x+1} = \frac{x^2(1 + 2/x + 1/x^2)}{x^2(1 + 3/x + 1/x^2)} = \frac{1 + 2/x + 1/x^2}{1 + 3/x + 1/x^2}. \]

Dado que 1/x y 1/x² tienden a 0 a medida que \(x\) tiende a infinito, se puede decir que:

\[ \frac{(x+1)^2}{x^2+3x+1} \approx 1 - \frac{1}{x}, \]

ya que el término 1/x domina sobre 1/x².

Paso 2: Tratar el Exponente y Aplicar la Propiedad Límite

Ahora evaluamos el límite original:

\[ \lim_{x\to +\infty}\left(1 - \frac{1}{x}\right)^{\ln x}. \]

Usamos la aproximación de que \( \left(1 + \frac{1}{y}\right)^y \approx e \) para \(y \to \infty\). Para nuestro caso, reemplazamos \(1/x\) por \(-1/x\), y el signo negativo sale con el exponente de \(e\):

\[ \lim_{x\to +\infty}\left(1 - \frac{1}{x}\right)^x = e^{-1}. \]

Sin embargo, el exponente es \(\ln x\) en vez de \(x\), entonces, aplicamos una aproximación más:

\[ \lim_{x\to +\infty}\left(1 - \frac{1}{x}\right)^{\ln x} = \left( e^{-1} \right) \approx 1 - \frac{1}{x} = e^{- \ln x / x}. \]

Para \(x \to +\infty\), el término \(\ln x / x\) tiende a 0 porque el logaritmo crece mucho más lento que el término lineal, mostrando que:

\[ e^{- \ln x / x} \to e^{0} = 1. \]

Conclusión

El valor del límite es:

\[ \lim_{x\to +\infty}\left(\frac{(x+1)^2}{x^2+3x+1}\right)^{\ln x} = 1. \]

Respuesta B

Sea

\[ L=\lim_{x\to +\infty}\left(\frac{(x+1)^2}{x^2+3x+1}\right)^{\ln x}. \]

1. Indeterminación

Cuando \(x\to+\infty\),

\[ \frac{(x+1)^2}{x^2+3x+1} =\frac{x^2+2x+1}{x^2+3x+1}\to 1, \qquad \ln x\to +\infty. \]

Luego estamos ante una indeterminación del tipo \(1^\infty\).

2. Tomamos logaritmos

Definimos

\[ y=\left(\frac{(x+1)^2}{x^2+3x+1}\right)^{\ln x}. \]

Entonces

\[ \ln y=\ln x\cdot \ln\!\left(\frac{(x+1)^2}{x^2+3x+1}\right). \]

Estudiamos este límite.

3. Simplificamos la base

Observamos que

\[ \frac{(x+1)^2}{x^2+3x+1} =\frac{x^2+2x+1}{x^2+3x+1} =1-\frac{x}{x^2+3x+1}. \]

Sea

\[ u_x=\frac{x}{x^2+3x+1}. \]

Entonces \(u_x\to 0\) cuando \(x\to+\infty\), y

\[ \ln y=\ln x\cdot \ln(1-u_x). \]

Usamos el equivalente notable:

\[ \ln(1-u)\sim -u \qquad (u\to 0). \]

Por tanto,

\[ \ln y \sim -\ln x\cdot \frac{x}{x^2+3x+1}. \]

Y como

\[ \frac{x}{x^2+3x+1}\sim \frac1x, \]

resulta

\[ \ln y \sim -\frac{\ln x}{x}. \]

Pero

\[ \lim_{x\to+\infty}\frac{\ln x}{x}=0. \]

Así,

\[ \lim_{x\to+\infty}\ln y=0. \]

4. Volvemos a la función original

Si \(\ln y\to 0\), entonces

\[ y\to e^0=1. \]

Por consiguiente,

\[ \boxed{\lim_{x\to +\infty}\left(\frac{(x+1)^2}{x^2+3x+1}\right)^{\ln x}=1.} \]
