Solucion oficial

Pregunta 4. Se considera la función \(f(x)=xe^{2x^2}\). Se pide:

(a) (1.5 puntos) Calcula una primitiva de \(f(x)\), que pase por el punto \((0,-1)\).
*Sugerencia: Puedes utilizar el cambio de variable \(t=2x^2\).*

Si hacemos el cambio de variable: \(2x^2=t\), \(4x\,dx=dt\), se tiene que

\[ \int xe^{2x^2}\,dx=\int \frac14 e^t\,dt=\frac14 e^t+k=\frac14 e^{2x^2}+k \]

Como debe pasar por \((0,-1)\), se tiene que

\[ \frac14+k=-1 \]

por lo que

\[ k=-\frac54. \]

(b) (1 punto) Calcula el área encerrada por la gráfica de \(f\), las rectas \(x=0\) y \(x=1\).

\[ xe^{2x^2}\ge 0 \]

siempre que \(x\ge 0\). El área pedida es

\[ \int_0^1 xe^{2x^2}\,dx = \frac14 e^{2x^2}\Big|_0^1 = \frac14 e^2-\frac14. \]

Respuesta A

Para resolver el ejercicio 4, vamos a abordar ambas partes del problema usando las técnicas adecuadas de cálculo integral.

Parte (a)

Pregunta: Calcula una primitiva de \(f(x) = xe^{2x^2}\) que pase por el punto \((0, -1)\).

Solución:

Como se sugiere usar el cambio de variable \( t = 2x^2 \), procedamos con esto. Haciendo el cambio de variable, primero calculamos \( dt \):

\[ dt = 4x \, dx \quad \Rightarrow \quad \frac{dt}{4} = x \, dx \]

Sustituimos en la integral:

\[ \int xe^{2x^2} \, dx = \int e^t \frac{dt}{4} = \frac{1}{4} \int e^t \, dt \]

La integral indefinida de \( e^t \) es conocidamente \( e^t \), por lo tanto:

\[ \frac{1}{4} \int e^t \, dt = \frac{1}{4}e^t + C \]

Regresando a la variable original, dado que \( t = 2x^2 \), tenemos:

\[ F(x) = \frac{1}{4}e^{2x^2} + C \]

Ahora, necesitamos encontrar el valor de \( C \) tal que la función primitiva pase por el punto \((0, -1)\).

\[ F(0) = \frac{1}{4}e^{2 \cdot 0} + C = \frac{1}{4} + C = -1 \]

Resolviendo para C:

\[ \frac{1}{4} + C = -1 \quad \Rightarrow \quad C = -1 - \frac{1}{4} = -\frac{5}{4} \]

Así, la primitiva que buscamos es:

\[ F(x) = \frac{1}{4}e^{2x^2} - \frac{5}{4} \]

Parte (b)

Pregunta: Calcula el área encerrada por la gráfica de \( f(x) = xe^{2x^2} \), las rectas \( x = 0 \) y \( x = 1 \).

Solución:

La fórmula para el área bajo la curva de una función \( g(x) \) desde \( a \) hasta \( b \) es:

\[ \text{Área} = \int_a^b |g(x)| \, dx \]

En este caso:

\[ \text{Área} = \int_0^1 |xe^{2x^2}| \, dx = \int_0^1 xe^{2x^2} \, dx \]

Utilizando el mismo cambio de variable propuesto anteriormente, y sabiendo que \( f(x) = xe^{2x^2} \) es positiva en \( [0, 1] \), tenemos:

\[ t = 2x^2, \quad dt = 4x \, dx, \quad \frac{dt}{4} = x \, dx \]

\[ \text{Área} = \int_0^1 xe^{2x^2} \, dx = \int_0^2 \frac{e^t}{4} \, dt = \frac{1}{4} \int_0^2 e^t \, dt = \frac{1}{4} [e^t]_0^2 = \frac{1}{4} (e^2 - 1) \]

El área encerrada por la curva es:

\[ \frac{e^2 - 1}{4} \]

Este valor es lo que se busca.

Respuesta B

Vamos a resolver los dos apartados.

Dada:

\[ f(x)=x e^{2x^2} \]

---

(a) Primitiva de \(f(x)\) que pasa por \((0,-1)\)

Buscamos \(F(x)\) tal que
\[ F'(x)=x e^{2x^2}. \]

Calculamos:
\[ \int x e^{2x^2}\,dx \]

Usamos el cambio sugerido:
\[ t=2x^2 \quad \Rightarrow \quad dt=4x\,dx \quad \Rightarrow \quad x\,dx=\frac{dt}{4}. \]

Entonces:
\[ \int x e^{2x^2}\,dx = \int e^t \frac{dt}{4} = \frac14 \int e^t\,dt = \frac14 e^t + C = \frac14 e^{2x^2}+C. \]

Ahora imponemos que pase por \((0,-1)\), es decir:
\[ F(0)=-1. \]

Sustituyendo:
\[ \frac14 e^{0}+C=-1 \quad\Rightarrow\quad \frac14 + C = -1 \quad\Rightarrow\quad C=-\frac54. \]

Por tanto, la primitiva pedida es:
\[ \boxed{F(x)=\frac14 e^{2x^2}-\frac54}. \]

---

(b) Área encerrada por la gráfica de \(f\), \(x=0\) y \(x=1\)

En el intervalo \([0,1]\),
\[ f(x)=x e^{2x^2}\ge 0, \]
así que el área es:
\[ A=\int_0^1 x e^{2x^2}\,dx. \]

Usando la primitiva:
\[ \int x e^{2x^2}\,dx=\frac14 e^{2x^2}+C, \]
tenemos:
\[ A=\left[\frac14 e^{2x^2}\right]_0^1 = \frac14 e^2 - \frac14 e^0 = \frac14(e^2-1). \]

Así, el área vale:
\[ \boxed{A=\frac{e^2-1}{4}}. \]

---

Respuesta final

(a) \(\displaystyle \boxed{F(x)=\frac14 e^{2x^2}-\frac54}\)

(b) \(\displaystyle \boxed{\frac{e^2-1}{4}}\)
