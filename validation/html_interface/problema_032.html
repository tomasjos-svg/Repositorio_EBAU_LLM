Solucion oficial

P6. - \[10 punts\] Calcula la integral de la funció
\[ f(x)=\frac{x^4+2x-6}{x^2+x-2}. \]

Solució.

\[ \int \left(\frac{x^4+2x-6}{x^2+x-2}\right)dx = \int \left(x^2-x+3+\frac{-3x}{x^2+x-2}\right)dx \]

\[ = \int (x^2-x+3)\,dx -3\int \left(\frac{x}{(x-1)(x+2)}\right)dx \]

\[ = \frac{x^3}{3}-\frac{x^2}{2}+3x -3\int \left(\frac{A}{x-1}+\frac{B}{x+2}\right)dx \]

Es troba que \(A=\frac13\) i \(B=\frac23\), i per tant,

\[ = \frac{x^3}{3}-\frac{x^2}{2}+3x -3\int \left( \frac{1}{3}\frac{1}{x-1} + \frac{2}{3}\frac{1}{x+2} \right)dx \]

\[ = \frac{x^3}{3}-\frac{x^2}{2}+3x -\left(\ln|x-1|+2\ln|x+2|\right)+C. \]

Respuesta A

Para resolver la integral dada

\[ \int \frac{x^4 + 2x - 6}{x^2 + x - 2} \, dx, \]

primero tratamos de simplificar el integrando. Observamos que el denominador \(x^2 + x - 2\) se puede factorizar:

\[ x^2 + x - 2 = (x - 1)(x + 2). \]

Ahora verifiquemos si el numerador se puede simplificar también, o bien si podemos aplicar división polinómica al numerador. Realizamos la división de \(x^4 + 2x - 6\) entre \(x^2 + x - 2\):

Dividimos \(x^4\) entre \(x^2\) para obtener \(x^2\). Multiplicamos \(x^2\) por \(x^2 + x - 2\) para obtener \(x^4 + x^3 - 2x^2\), y lo restamos del polinomio original:

\[ x^4 + 2x - 6 - (x^4 + x^3 - 2x^2) = -x^3 + 2x^2 + 2x - 6. \]

Repetimos el proceso: Dividimos \(-x^3\) entre \(x^2\) para obtener \(-x\). Multiplicamos \(-x\) por \(x^2 + x - 2\) para obtener \(-x^3 - x^2 + 2x\), y restamos:

\[ -x^3 + 2x^2 + 2x - 6 - (-x^3 - x^2 + 2x) = 3x^2 - 6. \]

Continuamos: Dividimos \(3x^2\) entre \(x^2\) para obtener \(3\). Multiplicamos \(3\) por \(x^2 + x - 2\) para obtener \(3x^2 + 3x - 6\), y restamos:

\[ 3x^2 - 6 - (3x^2 + 3x - 6) = -3x. \]

Esto nos muestra que

\[ x^4 + 2x - 6 = (x^2 - x + 3)(x^2 + x - 2) - 3x. \]

Sustituimos todo esto de vuelta en nuestra integral inicial:

\[ \int \frac{x^4 + 2x - 6}{x^2 + x - 2} \, dx = \int (x^2 - x + 3 - \frac{3x}{x^2 + x - 2}) \, dx. \]

Separando la integral:

\[ = \int (x^2 - x + 3) \, dx - \int \frac{3x}{x^2 + x - 2} \, dx. \]

La integral de polinomios es directa, mientras que para la fracción racional aplicamos una descomposición en fracciones parciales. Al primer término se integra como:

\[ \int (x^2 - x + 3) \, dx = \frac{x^3}{3} - \frac{x^2}{2} + 3x + C_1. \]

Para el segundo término, necesitamos hacer una descomposición en fracciones parciales. Considerando el denominador \((x - 1)(x + 2)\):

\[ \frac{3x}{x^2 + x - 2} = \frac{A}{x - 1} + \frac{B}{x + 2}, \]

encontrar A y B y luego integrar. Procede siguiendo estos pasos hasta la solución. Esto debería llevarte a la solución completa de la integral.

Respuesta B

Queremos calcular

\[ \int \frac{x^4+2x-6}{x^2+x-2}\,dx. \]

1. División de polinomios

Como el grado del numerador es mayor que el del denominador, dividimos:

\[ \frac{x^4+2x-6}{x^2+x-2}. \]

Haciendo la división:

\[ x^4+0x^3+0x^2+2x-6 = (x^2+x-2)(x^2-x+3)-3x. \]

Por tanto,

\[ \frac{x^4+2x-6}{x^2+x-2}=x^2-x+3-\frac{3x}{x^2+x-2}. \]

2. Descomposición en fracciones simples

Factorizamos el denominador:

\[ x^2+x-2=(x+2)(x-1). \]

Entonces

\[ -\frac{3x}{(x+2)(x-1)}=\frac{A}{x+2}+\frac{B}{x-1}. \]

Multiplicando por \((x+2)(x-1)\):

\[ -3x=A(x-1)+B(x+2). \]

Desarrollamos:

\[ -3x=(A+B)x+(-A+2B). \]

Igualando coeficientes:

\[ A+B=-3,\qquad -A+2B=0. \]

De la segunda, \(A=2B\). Sustituyendo en la primera:

\[ 2B+B=-3 \Rightarrow 3B=-3 \Rightarrow B=-1, \]
\[ A=-2. \]

Así,

\[ -\frac{3x}{(x+2)(x-1)}=-\frac{2}{x+2}-\frac{1}{x-1}. \]

Luego

\[ \frac{x^4+2x-6}{x^2+x-2}=x^2-x+3-\frac{2}{x+2}-\frac{1}{x-1}. \]

3. Integramos término a término

\[ \int \frac{x^4+2x-6}{x^2+x-2}\,dx = \int \left(x^2-x+3-\frac{2}{x+2}-\frac{1}{x-1}\right)\,dx. \]

Entonces:

\[ \int x^2\,dx=\frac{x^3}{3},\qquad \int (-x)\,dx=-\frac{x^2}{2},\qquad \int 3\,dx=3x, \]

\[ \int \frac{-2}{x+2}\,dx=-2\ln|x+2|,\qquad \int \frac{-1}{x-1}\,dx=-\ln|x-1|. \]

Resultado final

\[ \boxed{ \int \frac{x^4+2x-6}{x^2+x-2}\,dx = \frac{x^3}{3}-\frac{x^2}{2}+3x-2\ln|x+2|-\ln|x-1|+C } \]

donde \(C\) es la constante de integración.
