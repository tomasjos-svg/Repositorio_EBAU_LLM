Respuesta A

Queremos el área encerrada entre

\[ f(x)=x^3-3x^2+3x,\qquad g(x)=x. \]

1) Puntos de corte

Igualamos ambas funciones:

\[ x^3-3x^2+3x=x \]

\[ x^3-3x^2+2x=0 \]

\[ x(x^2-3x+2)=0 \]

\[ x(x-1)(x-2)=0 \]

Luego se cortan en:

\[ x=0,\;1,\;2. \]

2) Qué función va arriba en cada tramo

Estudiamos

\[ f(x)-g(x)=x(x-1)(x-2). \]

- En \((0,1)\): por ejemplo, en \(x=\tfrac12\),

\[ \tfrac12\left(-\tfrac12\right)\left(-\tfrac32\right)>0, \]

así que \(f(x)>g(x)\).

- En \((1,2)\): por ejemplo, en \(x=\tfrac32\),

\[ \tfrac32\left(\tfrac12\right)\left(-\tfrac12\right)<0, \]

así que \(f(x)<g(x)\).

Por tanto, el área total es

\[ A=\int_0^1 (f(x)-g(x))\,dx+\int_1^2 (g(x)-f(x))\,dx. \]

3) Cálculo de las integrales

Como

\[ f(x)-g(x)=x^3-3x^2+2x, \]

tenemos una primitiva:

\[ \int (x^3-3x^2+2x)\,dx=\frac{x^4}{4}-x^3+x^2. \]

Primer tramo

\[ A_1=\int_0^1 (x^3-3x^2+2x)\,dx \]

\[ A_1=\left[\frac{x^4}{4}-x^3+x^2\right]_0^1 =\left(\frac14-1+1\right)-0=\frac14. \]

Segundo tramo

\[ A_2=\int_1^2 -(x^3-3x^2+2x)\,dx \]

\[ A_2=-\left[\frac{x^4}{4}-x^3+x^2\right]_1^2. \]

Calculamos:

\[ \left(\frac{2^4}{4}-2^3+2^2\right)=4-8+4=0, \]

\[ \left(\frac{1^4}{4}-1^3+1^2\right)=\frac14. \]

Entonces

\[ A_2=-(0-\tfrac14)=\frac14. \]

4) Área total

\[ A=A_1+A_2=\frac14+\frac14=\frac12. \]

Resultado

\[ \boxed{\text{El área encerrada es } \frac12} \]

unidades cuadradas.

Respuesta B

Para resolver el ejercicio solicitado, calculamos el área de la región encerrada entre las curvas de las funciones \( f(x) = x^3 - 3x^2 + 3x \) y \( g(x) = x \).

Paso 1: Determinar los puntos de intersección

Primero encontramos los puntos donde las curvas \( f(x) \) y \( g(x) \) se intersectan. Para ello, igualamos las funciones:

\[ f(x) = g(x) \]
\[ x^3 - 3x^2 + 3x = x \]

Simplificando la ecuación, obtenemos:

\[ x^3 - 3x^2 + 3x - x = 0 \]
\[ x^3 - 3x^2 + 2x = 0 \]
\[ x(x^2 - 3x + 2) = 0 \]

Factorizando el trinomio:

\[ x(x-1)(x-2) = 0 \]

De aquí, las soluciones son:

\[ x = 0, x = 1, x = 2 \]

Estos valores de \( x \) son los puntos de intersección de las gráficas.

Paso 2: Calcular el área entre las curvas

Para hallar el área entre las curvas en los intervalos de intersección (\( x = 0 \) a \( x = 1 \) y \( x = 1 \) a \( x = 2 \)), calculamos la integral de la diferencia entre \( f(x) \) y \( g(x) \), en valor absoluto, en los intervalos respectivos. Observamos que entre \( x = 0 \) y \( x = 1 \), \( g(x) \) está por encima de \( f(x) \), y entre \( x = 1 \) y \( x = 2 \), \( f(x) \) está por encima.

La expresión para la integral del área queda como:

\[ \text{Área } = \int_{0}^{1} (x - (x^3 - 3x^2 + 3x)) \, dx + \int_{1}^{2} ((x^3 - 3x^2 + 3x) - x) \, dx \]

Simplificando las integrales:

\[ = \int_{0}^{1} (-x^3 + 3x^2 - 2x) \, dx + \int_{1}^{2} (x^3 - 3x^2 + 2x) \, dx \]

Paso 3: Resolver las integrales

Para \(\int_{0}^{1} (-x^3 + 3x^2 - 2x) \, dx\):

\[ \int (-x^3 + 3x^2 - 2x) \, dx = -\frac{x^4}{4} + x^3 - x^2 + C \]
Evaluando de \( 0 \) a \( 1 \):
\[ (-\frac{1^4}{4} + 1^3 - 1^2) - (0) = -\frac{1}{4} + 1 - 1 = -\frac{1}{4} \]

Para \(\int_{1}^{2} (x^3 - 3x^2 + 2x) \, dx\):

\[ \int (x^3 - 3x^2 + 2x) \, dx = \frac{x^4}{4} - x^3 + x^2 + C \]
Evaluando de \( 1 \) a \( 2 \):
\[ (\frac{2^4}{4} - 2^3 + 2^2) - (\frac{1^4}{4} - 1^3 + 1^2) = 4 - 8 + 4 - \left(\frac{1}{4}-1+1\right) = 3 - \frac{3}{4} = \frac{9}{4} \]

Paso 4: Sumar las áreas

\[ \text{Área total} = \left|-\frac{1}{4}\right| + \frac{9}{4} = \frac{1}{4} + \frac{9}{4} = \frac{10}{4} = 2.5 \]

Por lo tanto, el área encerrada entre las curvas es de \( 2.5 \) unidades cuadradas.
