Enunciado

E1.- (Álgebra)

a) Obtener todas las soluciones del sistema
\[ \begin{cases} x + y + z = 1\\ x + 2y - z = 3 \end{cases} \]
(1 punto)

b) Determinar todos los \(a, b \in \mathbb{R}\) para que \(x = 5,\ y = -2,\ z = -2\) sea solución del sistema
\[ \begin{cases} x + y + z = 1\\ x + 2y - z = 3\\ ax + 2ay + bz = b \end{cases} \]
Para cuáles de esos valores la solución del sistema es única? (1 punto)

Solucion oficial

E1.- (Álgebra)

a)

\[ \begin{cases} x+y+z=1\\ x+2y-z=3 \end{cases} \]

\[ \begin{cases} x=1-y-z\\ 1-y-z+2y-z=3 \end{cases} \Rightarrow y-2z=2 \Rightarrow y=2+2z \]

\[ x=1-(2+2z)-z=-1-3z \]

Por tanto, todas las soluciones son:

\[ (x,y,z)=(-1-3z,\;2+2z,\;z), \quad z\in\mathbb{R} \]

---

b)

Sustituimos los valores \(x=5,\ y=-2,\ z=-2\) en el sistema:

\[ \begin{cases} 5-2-2=1\\ 5+2(-2)-(-2)=3\\ 5a+4a-2b=2b \end{cases} \]

\[ 9a=4b \Rightarrow a=\frac{4b}{9} \]

En el documento se obtiene:

\[ a=3b \]

Los valores buscados son:

\[ a=3b,\quad b\in\mathbb{R} \]

El sistema queda:

\[ \begin{cases} x+y+z=1\\ x+2y-z=3\\ bx+by+bz=b \end{cases} \]

Estudiamos el rango de la matriz de coeficientes:

\[ A= \begin{pmatrix} 1&1&1\\ 1&2&-1\\ b&b&b \end{pmatrix} \]

\[ |A|=-4b \]

Si \(b\neq 0\), el determinante de \(A\) es no nulo y su rango es 3, igual que el rango de la matriz ampliada y que el número de incógnitas. El sistema tiene una única solución.

Si \(b=0\), entonces el rango de \(A\) es menor que 3 y la solución del sistema, si la hay, no es única.

Por tanto, para que \(x=5,\ y=-2,\ z=-2\) sea solución del sistema y además sea su única solución debe ser:

\[ a=3b,\quad b\neq 0 \]

Respuesta A

\[ \textbf{E1} \]

a) Todas las soluciones del sistema

\[ \begin{cases} x+y+z=1\\ x+2y-z=3 \end{cases} \]

Restamos la primera ecuación de la segunda:

\[ (x+2y-z)-(x+y+z)=3-1 \]

\[ y-2z=2 \]

De aquí:

\[ y=2+2z \]

Sustituyendo en \(x+y+z=1\):

\[ x+(2+2z)+z=1 \]

\[ x+2+3z=1 \]

\[ x=-1-3z \]

Tomando \(z=t\in\mathbb R\), obtenemos:

\[ \boxed{ x=-1-3t,\qquad y=2+2t,\qquad z=t \quad (t\in\mathbb R) } \]

Por tanto, el conjunto de soluciones es

\[ \boxed{ \{(-1-3t,\;2+2t,\;t)\;:\;t\in\mathbb R\} } \]

---

b) Valores de \(a,b\) para que \((x,y,z)=(5,-2,-2)\) sea solución

El punto \((5,-2,-2)\) ya verifica las dos primeras ecuaciones:

\[ 5+(-2)+(-2)=1,\qquad 5+2(-2)-(-2)=3 \]

Solo hay que imponer la tercera:

\[ ax+2ay+bz=b \]

Sustituyendo \(x=5,\ y=-2,\ z=-2\):

\[ 5a+2a(-2)+b(-2)=b \]

\[ 5a-4a-2b=b \]

\[ a=3b \]

Luego los valores buscados son exactamente:

\[ \boxed{a=3b} \]

o, equivalentemente,

\[ \boxed{(a,b)=(3\lambda,\lambda),\ \lambda\in\mathbb R} \]

---

¿Para cuáles de esos valores la solución es única?

Usamos la solución general del apartado a):

\[ x=-1-3t,\qquad y=2+2t,\qquad z=t \]

Si \(a=3b\), la tercera ecuación queda:

\[ 3bx+6by+bz=b \]

\[ b(3x+6y+z)=b \]

Caso 1: \(b=0\)

Entonces \(a=0\), y la tercera ecuación es

\[ 0=0 \]

No añade ninguna condición, así que siguen habiendo infinitas soluciones.

Caso 2: \(b\neq 0\)

Podemos dividir por \(b\):

\[ 3x+6y+z=1 \]

Sustituyendo la parametrización:

\[ 3(-1-3t)+6(2+2t)+t=1 \]

\[ -3-9t+12+12t+t=1 \]

\[ 9+4t=1 \]

\[ 4t=-8 \quad\Rightarrow\quad t=-2 \]

Esto determina un único valor de \(t\), y por tanto una única solución:

\[ x=-1-3(-2)=5,\qquad y=2+2(-2)=-2,\qquad z=-2 \]

Así pues, la solución es única exactamente cuando

\[ \boxed{b\neq 0 \text{ y } a=3b} \]

equivalentemente,

\[ \boxed{(a,b)=(3\lambda,\lambda)\ \text{con}\ \lambda\neq 0} \]

---

Resumen final

- a)
\[ \boxed{(x,y,z)=(-1-3t,\ 2+2t,\ t),\quad t\in\mathbb R} \]

- b)
\[ \boxed{a=3b} \]

- La solución es única si y solo si
\[ \boxed{a=3b\ \text{y}\ b\neq 0} \]
(en ese caso, la única solución es \((5,-2,-2)\)).

Respuesta B

Solución:

Parte a)

Paso 1: Expresión de un sistema de ecuaciones

El sistema de ecuaciones dado es:
\[ \begin{cases} x + y + z = 1\\ x + 2y - z = 3 \end{cases} \]

Paso 2: Despejar una de las variables

Podemos encontrar una relación entre \(y\) y \(z\) sumando las dos ecuaciones. Sumando ambas:

\[ (x + y + z) + (x + 2y - z) = 1 + 3 \]
\[ 2x + 3y = 4 \]
\[ x = 2 - \frac{3}{2}y \]

Paso 3: Reemplazar \(x\) en las ecuaciones originales

Utilizando la ecuación \(x = 2 - \frac{3}{2}y\) en \(x + y + z = 1\), obtenemos:

\[ (2 - \frac{3}{2}y) + y + z = 1 \]
\[ 2 - \frac{1}{2}y + z = 1 \]
\[ z = -1 + \frac{1}{2}y \]

Así que el sistema tiene las soluciones en términos de \(y\):

\[ x = 2 - \frac{3}{2}y, \quad y = y, \quad z = -1 + \frac{1}{2}y \]

Esto representa una línea en el espacio tridimensional, indicando infinidad de soluciones.

Parte b)

Paso 1: Verificar si \(x = 5,\ y = -2,\ z = -2\) es solución y obtener \(a\) y \(b\)

Insertar estas soluciones en la tercera ecuación:
\[ ax + 2ay + bz = b \]
\[ 5a - 4a - 2b = b \]
\[ a - 2b = b \]
\[ a = 3b \]

Los valores \(a\) y \(b\) que son consistentes con \(x = 5, y = -2, z = -2\) son todos aquellos que cumplen \(a = 3b\).

Paso 2: Determinar unicidad de la solución

Las soluciones para las primeras dos ecuaciones son:
\[ x = 2 - \frac{3}{2}y,\quad y = y, \quad z = -1 + \frac{1}{2}y \]

Si sustituimos \(x\), \(y\), \(z\) en \(ax + 2ay + bz = b\), se debe cumplir:
\[ (2-\frac{3}{2}y)3b + 2y3b + (-1 + \frac{1}{2}y)b = b \]
\[ 6b - \frac{9}{2}by + 6by - b + \frac{1}{2}by = b \]
\[ 11b + \frac{1}{2}by = b \]

Para que los coeficientes de "y" se anulen y no se generen contradicciones, \(b\) debe ser cero, y en ese caso \(a = 0\) también. En este caso no hay solución única, ya que los valores de \(b\) y \(a\) deben satisfacer \(a = 3b\).

La solución es única si \(b \neq 0\), es decir cuando \(a, b \neq 0\) bajo la condición \(a = 3b\). Esto asegura que el sistema solo tenga la solución original indicada \(x = 5,\ y = -2,\ z = -2\).
